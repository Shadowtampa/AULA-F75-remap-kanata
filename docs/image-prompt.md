# Prompt para gerar a imagem das camadas

Cole em um gerador de imagem. Se ele tiver dificuldade com três teclados numa imagem só, divida em três pedidos, sempre levando junto o bloco "PHYSICAL LAYOUT".

```
Create a set of 3 clean top-down technical diagrams of the same 75% mechanical keyboard (AULA F75 layout), one per layer, stacked vertically in a single image. Flat vector style, dark navy keycaps with yellow legends, black case, white background, perfectly legible text, no perspective, no people. Each diagram has its title above it.

PHYSICAL LAYOUT (same in all 3 diagrams), left to right per row:
Row 1: Esc, F1–F12, rotary knob.
Row 2: `, 1, 2, 3, 4, 5, 6, 7, 8, 9, 0, -, =, Backspace | Delete.
Row 3: Tab, Q, W, E, R, T, Y, U, I, O, P, [, ], \ | PgUp.
Row 4: Caps Lock, A, S, D, F, G, H, J, K, L, ;, ', Enter | PgDn.
Row 5: Left Shift, Z, X, C, V, B, N, M, comma, period, /, Right Shift, Up arrow | End.
Row 6: Ctrl, Win, Alt, Space, UTIL, Fn, Left, Down, Right arrows.
Keys with two legends: bottom = normal press, top = with Shift.

DIAGRAM 1 — "BASE LAYER"
All keys show standard legends, except these, highlighted in bright yellow:
- key left of 1: bottom "~", top "`"
- 6: bottom "6", top "^"
- key right of P: bottom "{", top "["
- second key right of P: bottom "}", top "]"
- third key right of P: bottom "\", top "|"
- key right of L: bottom "ç", top "Ç"
- second key right of L: bottom "~", top "^"
- key right of period: bottom "/", top "?"
Small labels: Tab "hold = NAV"; J "hold = ←"; UTIL key (right of Space) "tap = Ctrl, hold = UTIL".

DIAGRAM 2 — "UTIL LAYER — hold key right of Space"
UTIL key pressed and glowing orange. All other keys dimmed gray and blank, except these, bright yellow with large legends:
- Q: "/"
- W: "?"
- key right of P: bottom "´", top "`"
- second key right of P: "ª"
- third key right of P: "º"
- key right of L: bottom ";", top ":"
- second key right of L: bottom "\"", top "'"
- Z: "⏮ previous track"
- X: "⏯ play/pause"
- C: "⏭ next track"

DIAGRAM 3 — "NAV LAYER — hold Tab"
Tab key pressed and glowing blue. All other keys dimmed gray and blank, except these, bright blue with large legends:
- Y: "PgUp"
- U: "Home"
- I: "↑"
- O: "End"
- H: "PgDn"
- J: "←"
- K: "↓"
- L: "→"
- Backspace: "Delete"
The I-J-K-L keys form an inverted-T arrow cluster; make it visually prominent.
```
